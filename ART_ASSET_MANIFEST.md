# Art Asset Manifest — Picnic Symphony

All artwork should follow a hand-painted watercolor storybook style: soft imperfect ink contours, translucent washes, botanical details, warm natural light. No photorealism, no flat vector, no emoji, no 3D.

## Notes

- All files must be transparent PNG or WebP.
- Keep file sizes under 150 KB each (use TinyPNG or Squoosh).
- Artwork not yet supplied will render as a tinted watercolor silhouette with the item name — never as an emoji or broken image.
- Replace the placeholder by simply placing the file at the correct path. No code changes needed.
- Spirit artwork should be vertically oriented (portrait) with the character centered.
- Ingredient artwork should be roughly square with the subject filling ~80% of the canvas.
